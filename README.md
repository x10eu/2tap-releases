# 2Tap pour Windows

FPS tactique, Escarmouche en neuf rounds et multijoueur direct.

**[Télécharger le lanceur officiel](https://github.com/x10eu/2tap-releases/releases/latest/download/2Tap_Lanceur.zip)**

## Installation

1. Extraire le ZIP dans un dossier accessible en écriture, par exemple `Documents\Jeux\2Tap`.
2. Ouvrir **2Tap Launcher.exe**. Le jeu est téléchargé lors de la première installation.
3. Cliquer **JOUER** lorsque la vérification est terminée.

Vous avez déjà 2Tap ? Extraire le kit **dans le dossier contenant 2Tap.exe**. Le lanceur réutilisera les fichiers présents.

## Mises à jour

Le lanceur vérifie les nouvelles versions à chaque ouverture et télécharge les blocs manquants. Les sauvegardes restent sur votre PC. Une installation interrompue est restaurée ; les blocs téléchargés sont conservés pour la reprise.

Fermer le jeu avant une mise à jour. Le bouton **Vérifier les fichiers** répare les fichiers endommagés. Sans connexion, une installation existante peut être lancée hors ligne ; utiliser la même version que ses amis pour jouer ensemble.

Les fichiers `.bin` et `manifest.json` des Releases servent au lanceur. Il n'est pas nécessaire de les télécharger manuellement.

## Configuration

Windows 64 bits. Le kit du lanceur inclut son environnement : Unreal Editor et .NET ne sont pas requis. Le jeu peut nécessiter le composant Microsoft Visual C++ x64 fourni dans `Engine\Extras\Redist\en-us\vc_redist.x64.exe`.

Le programme n'a pas de certificat commercial Windows ; un avertissement de réputation peut apparaître. Télécharger le kit uniquement depuis cette page officielle.

Le guide inclus explique le multijoueur direct et les prérequis réseau. Le lanceur distribue les mises à jour du jeu ; il ne fournit pas de serveur de partie ni de relais réseau.
